## THE STORY

For the last 15 years, every smartphone you have ever owned ran one of two operating systems.

One harvests your data for advertising. The other locks you in a walled garden you can never leave. Both are controlled by trillion-dollar corporations with no financial incentive to put your privacy first.

**Crimson OS exists because that should not be the only choice.**

It is not a modified Android. It is not a Linux phone. It is not a concept. It is a hand-written mobile operating system built from first principles — original kernel, original scheduler, original TCP/IP stack, original security model. Zero code borrowed from Google, Apple, or the Linux kernel.

**We wrote 13,684 lines of original C and ARM64 assembly. The code is real. The kernel boots. This campaign funds the next phase.**

## RISKS AND CHALLENGES

**This is a software-only campaign.** There is no hardware to manufacture, no supply chain, and no FCC certification required at this stage. The code is already written and publicly auditable.

**The main risk is time.** Porting a kernel to real hardware always surfaces unexpected driver issues. We are committing to full transparency: every dev update, every setback, and every milestone will be communicated to backers in real time via campaign updates.

We are not asking you to trust a vision. We are asking you to fund work already in progress.

## ABOUT THE PROJECT

Crimson OS is an independent, open-source mobile operating system licensed under GPLv3. It targets ARM64 devices (PinePhone, Librem 5, Raspberry Pi 4) and is designed from the ground up for security, privacy, and user sovereignty.
