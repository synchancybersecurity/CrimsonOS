HARDWARE CORRECTION

Community feedback corrected our hardware targeting. The PinePhone Pro uses the Rockchip RK3399, not the Allwinner A64. We rewrote our hardware definitions (rk3399.h), display scaffold (display_rk3399_dsi.h), and Makefile target (BOARD=pinephone-pro) to match the correct silicon. Remaining driver rewrites (touch, WiFi, modem, power, GIC) are in progress.

ROADMAP

✅ COMPLETE · MAY 2026

Kernel Alpha — First Boot Verified

13,684 lines of original C/ARM64 Assembly. All 8 init phases verified in QEMU. Interactive shell with 28 commands. Scheduler, memory manager, TCP/IP stack, security model, sandbox, IPC, display pipeline, touch pipeline, BloodMoon browser, NetWiz arsenal all built. GitHub live.

✅ COMPLETE · MAY 2026

Community Launch

Open sourced under GPLv3. Featured in r/degoogle, r/opensource, r/pinephone, r/PINE64official. GitHub repo live with all 86 source files. Campaign page live.

✅ COMPLETE · MAY 2026

Core Subsystems — Real Implementations

AES-256-GCM on ARM64 hardware crypto instructions (AESE/AESMC/PMULL). ChaCha20 CSPRNG seeded from ARM generic timer. VFS syscalls wired end-to-end. CrimsonFS indirect blocks — files up to 1 GB. Full 4-level ARM64 page table walk (fork, unmap, process exit). RK3399 MIPI DSI pipeline and XBD599 panel init for PinePhone Pro. GT917S touch driver over RK3399 I2C5 (DesignWare). Real DNS resolution over UDP + HTTP GET over TCP. Shell ls/cat reading live from CrimsonFS. Zero-warning build. CI badge passing on every commit.

RISKS & HONESTY

This is a software project. There is no hardware to manufacture, no supply chain to manage, and no FCC certification required. The kernel is already written and the code is publicly auditable.

The primary risk is time. Porting a kernel to new hardware always takes longer than expected. We are committing to transparency: every development update — including setbacks — will be shared with backers in real time.
